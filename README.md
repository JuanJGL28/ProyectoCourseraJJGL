# Proyecto Coursera - Little Lemon

Proyecto final del curso **Meta Front-End Developer Capstone**.

**Autor:** Juan Gomez (JJGL)

La aplicación está desarrollada con React y permite navegar por la página principal de Little Lemon y realizar una reserva de mesa seleccionando fecha, hora, número de comensales y ocasión.

## Funcionalidades principales

- Página principal responsive de Little Lemon.
- Navegación con React Router.
- Sección de platos especiales, testimonios y presentación del restaurante.
- Formulario de reserva con validaciones básicas.
- Consulta de horarios disponibles según la fecha.
- Pantalla de confirmación de reserva.
- Pruebas con React Testing Library.

## Ejecución local

```bash
npm install
npm start
```

## Pruebas

```bash
npm test
```
